# Week 7 - Extended Controlled Experiment

## Purpose

Week 7 extends the Week 5 1-epoch comparison to a 3-epoch controlled experiment.

Comparison groups:
1. Baseline YOLOv9-S + NMS
2. Proposed V10DualDDetect + NMS
3. Proposed V10DualDDetect + no-NMS

Default setting:
- COCO128
- Image size 320
- Epochs 3
- Batch 4
- Colab free-tier compatible

This is not a full COCO final experiment.
